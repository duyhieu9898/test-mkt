
# Banner Generation Tool

Purpose:
Generate ad banners automatically.

Inputs:

product_description
target_audience
platform
style

Example Flow:

Marketing Agent
↓
Generate banner prompt
↓
Image Generation API
↓
Generate variations
↓
Resize for ad formats

Possible Providers:

- OpenAI image models
- Stable Diffusion
- Midjourney
- Banana inference APIs

Outputs:

banner_url
variants
platform_sizes
