# CEO Dashboard Spec

## Purpose

Mission control interface for the founder to monitor and control AI-run
companies.

## Main Sections

-   Company Health Score
-   CEO Inbox / Decision Feed
-   Budget Overview
-   Strategy Timeline
-   Agent Performance
-   Audit Log

## Company Health Widget

Health score range: 0--100

Factors: - revenue growth - task success rate - budget efficiency -
system stability - agent performance
