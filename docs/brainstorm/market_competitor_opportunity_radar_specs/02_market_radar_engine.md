
# Market Radar Engine

Purpose:
Detect fast-growing topics and market signals.

Input Sources:
- search trends
- social media discussions
- startup launches
- industry news

Detection Methods:

Keyword Velocity
Detect keywords growing rapidly.

Topic Clustering
Group related discussions into trends.

Audience Detection
Identify which user groups are driving growth.

Example Output:

Trend Topic: AI YouTube thumbnail generators
Growth: +145%
Audience: YouTube creators
