
# Hybrid Template System Overview

Purpose:
Enable AI Company OS to generate companies using a hybrid approach:

Base Templates
+
AI Customization
+
Dynamic Playbooks
+
Template Marketplace

Why Hybrid:
Pure templates are too rigid.
Pure AI generation is inconsistent.

Hybrid allows:
- fast onboarding
- consistency
- deep customization

Core Components:

1. Template Library
2. AI Customization Engine
3. Playbook Engine
4. Template Marketplace
5. Template Ranking System
