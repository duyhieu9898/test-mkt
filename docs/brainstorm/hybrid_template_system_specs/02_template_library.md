
# Template Library

Purpose:
Store base templates for different industries and business models.

Template Layers:

Industry Layer
- SaaS
- Ecommerce
- Marketplace
- Agency
- Creator Business
- Local Services

Business Model Layer
- Subscription
- One-time purchase
- Transaction fee
- Advertising
- Services

Audience Layer
- Developers
- Creators
- SMB
- Consumers
- Enterprise

Template Object Structure:

template_id
industry
business_model
audience
default_agents
default_playbook
default_metrics
