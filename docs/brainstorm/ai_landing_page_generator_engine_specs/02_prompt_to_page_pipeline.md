
# Prompt → Landing Page Pipeline

Step 1: User Prompt
User describes business idea.

Step 2: Business Understanding
AI extracts:
- target audience
- product/service
- main value proposition

Step 3: Page Structure Generation
Generate sections:
Hero
Problem
Solution
Features
Pricing
Testimonials
Call-to-action

Step 4: Content Generation
Generate headlines, descriptions, CTA text.

Step 5: Asset Generation
Generate images and banners.

Step 6: Page Assembly
Build page components.

Step 7: Deployment
Publish site automatically.
