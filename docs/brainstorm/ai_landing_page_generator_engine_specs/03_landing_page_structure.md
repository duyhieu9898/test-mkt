
# Landing Page Structure

Standard layout:

1. Hero Section
- headline
- subheadline
- call-to-action

2. Problem Section
Explain user pain points.

3. Solution Section
Describe product solution.

4. Features Section
Key product capabilities.

5. Pricing Section
Pricing tiers.

6. Social Proof
Testimonials or metrics.

7. Final CTA
Lead capture form.
