# Chatbot Brain

## Intent Detection
- pricing inquiry
- service inquiry
- comparison
- objection
- general question

## Funnel Stages
- awareness
- consideration
- decision

## Behavior Rules

IF awareness:
- ask clarifying questions
- do not push price

IF consideration:
- explain benefits
- provide examples

IF decision:
- provide pricing
- give CTA (book call, buy)

## Example

User: "giá bao nhiêu?"

IF awareness:
→ "Bạn đang tìm giải pháp cho mục tiêu gì?"

IF decision:
→ "Gói của chúng tôi bắt đầu từ $99, bạn muốn mình tư vấn gói phù hợp không?"
