AGENT COMMUNICATION PROTOCOL
============================

Message Structure:
{
  "sender": "agent-uuid",
  "receiver": "agent-uuid",
  "messageType": "task_delegation|request_help|decision_request|...",
  "priority": "critical|high|normal|low",
  "goal": "What sender wants to achieve",
  "context": {
    "taskId": "...",
    "situation": "...",
    "relevantData": {...}
  },
  "constraints": {
    "deadline": "ISO date",
    "budget": 100,
    "requiredCapabilities": [...]
  },
  "expectedOutput": {
    "format": "task_result|decision|information|...",
    "description": "What sender expects back"
  },
  "content": {
    "summary": "Brief summary",
    "details": "Full details",
    "actions": [...],
    "recommendations": [...]
  }
}
