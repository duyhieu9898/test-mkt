01

概要と業務フロー

1Personは、会社情報をAIに学習させ、優先事項の提案、マーケティング・営業施策の作成、結果の分析までを一つのワークスペースで行うシステムです。

  1. 会社情報を登録
  2. AIが学習
  3. 優先事項を提案
  4. 施策を作成・実行
  5. 結果を分析・改善

このマニュアルの使い方

利用者最初に読む場所目的
初めて利用する方30分クイックスタート最小限の設定で最初の施策まで進む
日々の運用担当ダッシュボード、CEOアドバイザー今日の優先事項とレビュー待ち成果物を確認する
制作・マーケティング担当キャンペーン、ランディングページ生成、レビュー、公開まで安全に進める
オーナー・管理者ロールと権限、安全な利用メンバー、クレジット、外部連携を管理する

最初に進める順番

  1. AIに正しい会社情報を教える

    Knowledge、Brand IQ、Brainで商品、顧客、ブランドトーン、FAQを整えます。

  2. CEOアドバイザーを確認する

    会社データを横断した提案を読み、最重要アクションから着手します。

  3. 施策を実行する

    キャンペーン、市場、営業など目的に合う画面へ移動します。

  4. 結果を学習へ戻す

    分析、競合情報、会議の決定事項を次の提案と生成物へ反映します。

おすすめ

初日はすべてを設定する必要はありません。「Knowledge → Brand IQ → CEOアドバイザー → 最初の施策」の順で進めます。

画面と本書の表記が異なる場合

機能の提供状況や消費クレジットは契約・権限・接続状況によって変わります。操作直前に画面へ表示される内容を優先し、不明な場合はオーナーまたはサポートへ確認してください。

03

アカウント作成・ログイン

新規登録

/register
  1. 氏名を入力

    2文字以上で入力します。

  2. メールアドレスを入力

    会社で利用できる有効なメールアドレスを使います。

  3. パスワードを作成

    8文字以上、英字と数字を含めます。

  4. アカウント作成を押す

    承認が必要な環境では、管理者承認後にログインできます。画面上の目安は通常24時間以内です。

ログイン

/login
  1. メールアドレスとパスワードを入力

    入力エラーはフィールド下のメッセージで確認します。

  2. ログインを押す

    処理中はボタンが無効になります。重複クリックしないでください。

  3. 遷移先を確認

    新規ユーザーは初回セットアップ、設定済みユーザーは会社一覧へ進みます。システム管理者には管理画面が表示される場合があります。

パスワードを忘れた場合

現在、セルフサービスのパスワード再設定は利用できません。ログイン画面のリンクは使用せず、会社のオーナーまたは support@1person.ai へ連絡してください。

04

初回セットアップ

/welcome

開始前に準備するもの

  • 会社で利用できるメールアドレスと、自分のロール。
  • 既存のWebサイトURL。Webサイトがない場合は、事業概要、対象顧客、商品・サービス、強み。
  • 確認できる担当者。AIが抽出した会社名、商品、顧客情報は人が承認します。
  • 必要に応じて商品資料、FAQ、料金表、ブランド資料。パスワードや秘密鍵は含めません。
  1. 表示・生成言語を選ぶ

    日本語を選ぶと、AI生成コンテンツも日本語が基本になります。

  2. 開始方法を選ぶ

    「まだWebサイトがありません」または「Webサイトがあります」を選択します。

  3. 事業情報を入力

    新規事業は顧客、課題、商品、強みを記載します。既存サイトがある場合はURLを入力します。

  4. AI分析を待つ

    事業理解、サイト分析、AIチーム、成長戦略、ブランド設定が順番に処理されます。

  5. 事業理解の結果を確認

    会社名、業界、モデル、顧客、商品、提供価値、成長方針を確認し、必要なら編集します。

  6. AIチームと成長プランを承認

    担当内容と優先施策を確認して実行を開始します。

  7. ダッシュボードへ移動

    セットアップ完了後、作成した会社のダッシュボードへ進みます。

セットアップ完了の目安

正しい会社名と対象顧客が表示され、AIチームと成長プランを確認でき、ダッシュボードへ移動できれば完了です。

入力例

「日本の中小製造業向けに、見積作成を自動化するSaaS。営業責任者が主な利用者。導入の早さと日本語サポートが強み。」

承認前の確認

会社名と対象顧客、商品内容、ブランド表現の3点に重大な違いがないか確認してください。

07

KnowledgeとBrand IQ

Knowledgeに信頼する情報を追加

/{companyId}/knowledge
  • ファイルをアップロードします。1ファイル10MB未満です。
  • WebサイトURL、またはタイトルと詳細テキストを直接登録できます。
  • AIの抽出結果をプレビューして承認します。
  • 公開範囲を public、internal、confidential から選びます。
  • AI Extracted、Raw Content、How AI Uses Thisで内容を確認します。
Knowledge登録完了の目安

内容をプレビューし、事実が正しいことと公開範囲を確認して承認済みになれば、AIが参照できる状態です。古い資料や重複資料は定期的に整理してください。

Webサイトと公開情報を取り込む

/{companyId}/knowledge/crawl

Brand IQを確認

/{companyId}/brand-iq
  • Webサイトや補足コンテキストからBrand IQを生成します。
  • ブランドボイス、対象顧客、ポジショニング、視覚情報、ロゴ、色、フォント、OKRを編集します。
  • 保存後、ブログ、広告、SNS、LP、チャット回答などがこの基準を参照します。
出力が的外れな場合

プロンプトを増やす前に、KnowledgeとBrand IQの事実、顧客、トーンを修正してください。

10

キャンペーン作成・レビュー

/{companyId}/campaigns
作成前の確認

対象顧客、商品・オファー、ブランドボイス、公開責任者、使用可能なクレジットを確認します。情報が不足している場合は、先にKnowledgeまたはBrand IQを更新してください。

  1. Brain Readinessを確認

    ブランドボイス、主要ペルソナ、商品情報が正しいことを確認します。

  2. Generate Campaignを押す

    作成権限とクレジット消費権限が必要です。

  3. 目標と対象顧客を入力

    地域、業種、役職、課題まで具体的にします。

  4. 参照資料を選ぶ

    商品、オファー、ポジショニング資料を追加します。

  5. 品質ティアを選ぶ

    Fast、Balanced、Premiumから選び、表示クレジットを確認して生成します。

  6. 生成中の進捗を確認

    詳細画面の進捗パネルでReadyまたはFailedになるまで待ちます。

キャンペーンランチャーで作成

/{companyId}/launch

レビューから開始まで

/{companyId}/campaigns/{campaignId}
  1. Planを確認
  2. バナー・投稿を編集
  3. 根拠を確認
  4. Launch
  5. Learnで改善

キャンペーン動画を作成

  1. Videosで形式を選ぶ

    公開先に合わせてVerticalまたはWideを選び、「Create AI video」を押します。

  2. 動画の焦点を入力

    強調したい商品、対象顧客、雰囲気、伝えたい内容を具体的に入力します。空欄でも作成できます。

  3. 画像ソースを選ぶ

    必要に応じて画像をアップロードするかDriveから選択します。画像を選ばない場合は、キャンペーン情報からAIが映像を作成します。

  4. クレジットを確認して作成

    ボタンに表示される消費クレジット（画面例では50）を確認し、「Create video」を押します。

  5. 生成結果をレビュー

    内容、縦横比、テキスト、ブランド表現を確認してから公開対象へ追加します。

公開前の最終確認

  • 対象顧客、商品名、価格、日付、地域、CTAがキャンペーン計画と一致している。
  • 画像、音楽、ロゴ、引用、人物情報を公開できる権利がある。
  • リンク先が正しく、フォーム送信とモバイル表示を確認している。
  • 公開するSNS投稿・バナー・ブログだけを選択している。
  • チャネル、公開日時、消費クレジット、最終承認者を確認している。
人による承認が必要です

AIの生成物をそのまま公開しないでください。誤情報、価格、日付、権利関係、個人情報、リンク先、ブランドトーンを確認し、責任者の承認後にLaunchします。

開始完了の目安

キャンペーンがreadyまたは公開待ちの状態になり、選択した成果物と公開先をLaunch readinessで確認できればレビュー工程は完了です。

市場・競合分析

/{companyId}/market
  1. 競合を追加

    名称、WebサイトURL、最大3件のキーワード、メモを入力します。

  2. AI提案を使う

    Suggested competitorsで候補を生成し、個別または一括で追加します。

  3. Scan nowを実行

    表示クレジットを確認し、Webサイトやニュースのシグナルを取得します。

  4. シグナルを確認

    価格変更、製品発表、採用、ニュース、コンテンツを読み、推奨アクションを判断します。

  5. 情報を更新

    必要に応じてURL、キーワード、メモを編集します。

良いキーワード

ブランド名に加え、pricing、launch、fundingや主要商品のカテゴリ語から、意思決定に使う3件を選びます。

14

営業とAI Deal Assistant

/{companyId}/sales

商談はDiscovery → Qualified → Proposal → Negotiation → Won／Lostの6列で管理します。

  1. New dealを押す

    タイトルは必須です。連絡先、会社名、金額、初期ステージを入力します。

  2. 商談カードを開く

    ステージ、金額、通貨、次のアクション、メモを更新します。

  3. Ask AI Assistantを実行

    画面表示では1回3クレジットです。次の行動、理由、想定反論、メール案、信頼度を返します。

  4. 提案を採用

    Set as next actionで反映します。メール案はコピーし、外部メールで確認して送信します。

  5. Timelineを確認

    作成、ステージ変更、AI提案などの履歴を確認します。

メール送信

Deal Assistantはメール案を作成しますが、このフローでは自動送信しません。宛先、価格、日付、敬称、機密情報を確認してください。

15

会議・議事録・学習ループ

/{companyId}/meetings
  1. 入力方法を選ぶ

    ブラウザ録音、音声ファイル、またはタイトルと議事録テキストを使います。

  2. マイク権限を許可

    録音未対応のブラウザでは音声アップロードを使います。

  3. AI分析を待つ

    文字起こし、要約、決定事項、タスク、キーワード、戦略・市場・営業の示唆を生成します。

  4. 結果をレビュー

    誤認識を修正し、必要なら再分析します。

  5. Approveを実行

    承認した知見がKnowledgeやBrainへ入り、次の提案で利用されます。

  1. 録音・議事録
  2. AI要約
  3. 人が承認
  4. Knowledge・Brain
  5. 次回提案へ反映
音声解析を利用できない場合

音声アップロード後に手動議事録の追加を案内された場合は、文字起こしテキストを貼り付けて分析します。

安全に利用するために

1Personへ登録した情報はAIの提案や生成物で参照されます。必要な情報だけを登録し、公開前には必ず人が確認してください。

情報を追加するとき

  • Knowledgeの公開範囲は、用途に合わせてpublic、internal、confidentialから選びます。
  • パスワード、API key、token、秘密鍵、カード情報はKnowledgeやプロンプトへ入力しません。
  • 個人情報、顧客情報、契約情報は、社内ルールと利用目的を確認してから登録します。
  • 不要になった資料、古い価格、終了したキャンペーン情報は更新または削除します。

公開・外部連携するとき

  • 公開操作は権限を持つ担当者が行い、対象ページ・投稿・チャネルを再確認します。
  • Facebook、Google Analytics、WordPressなどの連携先では、必要最小限の権限を使用します。
  • 担当者の変更や利用終了時は、チーム権限と外部連携を速やかに見直します。
  • AIが生成した事実、数値、引用、著作物、人物画像は、責任者が確認してから公開します。
スクリーンショットを共有する前に

氏名、メールアドレス、顧客情報、URL内のtoken、請求情報、認証情報を隠してください。サポートに送る場合も同じです。
